# 🗼 Tokyo - Locais Turísticos

Este projeto é uma página web estática que apresenta alguns dos pontos turísticos mais icônicos de Tóquio, no Japão. A proposta é oferecer uma experiência visual e informativa sobre locais como o Palácio Imperial, o Santuário Meiji, Shibuya, entre outros. O conteúdo é inteiramente em português e voltado a viajantes e curiosos interessados na cultura e nos atrativos da capital japonesa.

## ✅ Funcionalidades Disponíveis

- Exibição de imagens e descrições de 6 pontos turísticos de Tóquio
- Navegação interna por âncoras para facilitar o acesso a cada seção
- Vídeos incorporados do YouTube para visualização imersiva
- Dicas, curiosidades e informações úteis sobre cada local
- Layout adaptado para dispositivos móveis e telas maiores

---

## 🌟 Features

- 🎨 **Design responsivo:** ajusta-se automaticamente entre dispositivos móveis e desktops usando `media queries`
- 🧭 **Layout flexível com Flexbox** para uma estrutura adaptável e harmônica
- 📸 **Galeria de imagens com hover interativo** e bordas arredondadas
- 📹 **Vídeos do YouTube embutidos** lado a lado com imagens em telas maiores
- 🖼️ **Cabeçalho com background personalizado** e fontes serifadas que combinam com a temática tradicional japonesa
- 🧾 **Texto formatado com bordas decorativas**, realçando legibilidade e estética
- ⚙️ **Separação clara das seções** com uso de `section`, `article` e `figure`

---

## 🛠 Tecnologias Utilizadas

- **HTML5**: estrutura semântica e organizada
- **CSS3**: estilos visuais com uso de:
  - Flexbox
  - Media queries para responsividade
  - Estilização de tipografia, imagens e interações
- **YouTube Embed**: integração de vídeos
- **Imagens locais**: ilustrações diretas do diretório do projeto
